# قارئ القرآن - mizouh المتميز (v3.0.0)

بلوجن احترافي للقرآن الكريم لأجهزة **Enigma2** (OpenATV / OpenPLi / OpenBH / Egami / Pure2 / VTi) مع دعم **التحديث التلقائي الجماعي عبر GitHub**.

## رقم الإصدار الحالي: `v3.0.0`

### أبرز المميزات
- تلاوة متصلة بدون انقطاع لـ **31 قارئاً** بروايتي **حفص عن عاصم** (بما فيهم الشيخ **أحمد بن علي العجمي**) و**ورش عن نافع**.
- عرض **صورة المصحف الشريف الحقيقية** (604 صفحة) بنقاء تام وبدون أي تظليل مزعج مع تقليب تلقائي للصفحات.
- وضع **الاستماع الصوتي فقط** (إظهار / إخفاء المصحف بالزر الأصفر).
- **التفسير المرافق** (التفسير الميسر، الجلالين، البغوي، الإنجليزية، الفرنسية) + **البحث المتقدم** + **التحميل بدون إنترنت**.
- **تحديث تلقائي دوري عبر GitHub**: بمجرد رفع إصدار جديد هنا، يتحدّث البلوجن تلقائياً لدى جميع الزبائن دفعة واحدة.

---

## أمر التثبيت بسطر واحد للزبائن (Telnet / SSH)

```sh
wget -q --no-check-certificate "https://raw.githubusercontent.com/mizouh1984/quran_mizouh/main/install_quran_mizouh_allinone.sh" -O - | /bin/sh
```

---

## كيف تدفع تحديثاً جديداً لجميع الزبائن دفعة واحدة؟

1. افتح مستودعك هذا على GitHub (`mizouh1984/quran_mizouh`).
2. ارفع الملفات المحدّثة برقم إصدار أعلى (مثلاً من `3.0.0` إلى `3.0.1`):
   - `version.json` (غيّر رقم `version` إلى الرقم الجديد)
   - `enigma2-plugin-extensions-quranmizouh.tar.gz`
   - `reciters_feed.json` (لإضافة قراء جدد فورياً)
   - `install_quran_mizouh_allinone.sh`
3. بمجرد أن يفتح أي زبون البلوجن على جهاز Enigma2، سيكتشف الإصدار الجديد تلقائياً ويحمله ويثبته ويعيد تشغيل الواجهة!

### ملاحظة لإضافة قراء جدد فقط بدون إعادة تشغيل:
يكفي تعديل ملف `reciters_feed.json` فقط على GitHub وسيتحدّث تلقائياً في أجهزة جميع الزبائن عند فتح البلوجن.
